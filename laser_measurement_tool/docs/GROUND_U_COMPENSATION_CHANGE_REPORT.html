主要改动

模块改动
config_loader.py支持 validation v2 CSV；规范化为 column_u_px / bias_mm
reconstructor.py新增 apply_ground_u_compensation，并接入 reconstruct_uv_to_ground
measure_tool.yaml切换到 0728 内参、激光平面、地面外参和补偿表
main_window.py保存结果时记录补偿文件路径
height_measure.py / main_window.py未选择基准 ROI 时自动使用固定 Zg=0；不伪造地面噪声和基准夹角
result_io.py / main_window.py保存整幅激光线补偿后的地面系点云 full_laser_ground.ply
backends.py接入实验版 Steger/Hessian 亚像素算法，修复轴对齐退化并支持水平/竖直扫描
roi_manager.py / main_window.py多个基准 ROI 合并拟合；多个障碍物 ROI 编号后分别重建、拟合、显示和保存
tests覆盖 CSV 加载、插值、端点钳位、关闭和非法表格

关键约定

Zg_corrected = Zg_raw - bias(u)。表内空缺线性插值，表外使用最近端点；配置为 null 时不改变原始重建行为。

完整命令、参数和迁移说明见同目录 GROUND_U_COMPENSATION_GUIDE.md。
