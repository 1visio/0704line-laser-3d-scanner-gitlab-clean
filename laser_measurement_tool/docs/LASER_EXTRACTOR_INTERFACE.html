激光中心提取接口改动说明

图例

颜色含义
蓝色GUI 与稳定接口
紫色centroid / Steger 算法 backend
绿色叠加显示和 CSV 输出
红色未配置算法时的明确提示

主要改动

  • 新增 extract_laser_center(image, params)，输出统一为 N×2 亚像素坐标。
  • 内置 centroid 与 Steger；Steger 使用高斯导数、Hessian 主曲率和二阶泰勒亚像素定位。
  • Steger 修复了实验版在严格水平/竖直条纹上的特征向量退化，并加入条纹带裁剪。
  • 提取成功后显示绿色中心点，并保存带 u,v 表头的 CSV。
  • 输出文件自动追加序号，避免覆盖历史结果。
